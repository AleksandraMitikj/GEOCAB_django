# 🚕 GEOCAB

Веб апликација за такси платформа во Скопје. Возачи (приватни лица регистрирани од GEOCAB)
и патници се поврзуваат преку мапа. Возачот добива дел од секое возење, а платформата задржува провизија.

Изградена со **Django 6** врз **PostgreSQL + PostGIS** база, каде најголемиот дел од правилата
(статуси, цени, казни, провизија, долг) се во самата база - тригери, функции и процедури.

---

## Што може апликацијата

### 👤 Корисник (патник)
- регистрација, најава, промена и заборавена лозинка, уредување профил
- избор на почеток и дестинација на **мапа** (адресата се пополнува сама), пат по улиците
- **проценка на цена** по вистински пат (OSRM) за секоја класа возило, 20% попуст над 10 km
- барање возење - системот го наоѓа **најблискиот слободен возач** во радиус од 10 km
- **мапа во живо**: каде е возачот и за колку минути пристигнува
- откажување (бесплатно / 50% / 100% од почетната цена, зависно од статусот)
- **пријава на проблем** во тек на возење + броеви за итни случаи (192, 194, 193, 112)
- плаќање **во готовина или со картичка** (демо платежна порта), оценка на возачот, историја на возења, 🔔 известувања

### 🚗 Возач
- смена со избор на возило и локација, **GPS во живо** додека е на смена
- понуди со **5 минути** за одговор (без одговор -> оди кај следниот возач)
- тек: прифати → пристигнав → почни → заврши, откажување, „корисникот не дојде“
- **мапа со пат** до корисникот и до дестинацијата, упатства чекор по чекор,
  копчиња за **Google Maps** (возач → корисник → дестинација) и **Waze**
- наплата во готовина или чекање плаќање со картичка, профил со заработка и пребивање со GEOCAB
  (провизија од готовина минус заработка од картички)

### 🛠 Администратор (`/manage/`)
- dashboard: возења, приход на платформата, должници, отворени пријави
- регистрирање и уредување возачи и возила, блокирање, нова лозинка
- евидентирање уплати на провизија; **месечен рок** - опомена од 15-ти, автоматска блокада од 1-ви
- сите возења со филтри, итно откажување (и во тек), враќање пари
- поставки: провизија, цени по класа, нови класи; корисници (блокирање, лозинка); пријави на проблем

Django `/admin/` останува за развој (директен пристап до табелите, додавање нов администратор).

## Технологии

| | |
|---|---|
| Backend | Python 3.14, Django 6.1, psycopg 3 |
| База | PostgreSQL 18 + PostGIS (Postgres.app на macOS) |
| Frontend | Django шаблони, Bootstrap 5, Leaflet + OpenStreetMap |
| Рути | OSRM (пат по улиците, време), Nominatim (адреса од координати) |

## Структура

```
GEOCAB/                 поставки на проектот (settings.py, urls.py)
GEOCAB_APP/
  models.py             модели врз постоечките табели (managed = False)
  db.py                 повикување на SQL функциите и процедурите
  views.py              корисник и возач
  manage_views.py       админ панел (/manage/)
  account_views.py      профил и лозинки
  auth.py               најава за корисник / возач / администратор
  routing.py            растојание по пат (OSRM)
  templates/, static/   страници, CSS, JS (мапи), SVG илустрации
  management/commands/seed.py   тест податоци
  tests/                автоматски тестови
database/
  geocab_schema.sql     цела шема: табели, индекси, функции, тригери, views
  geocab_lookup_data.sql задолжителни шифрарници (статуси, пораки, провизија)
  geocab_upgrade.sql    надградба на постара база (секции 1-5)
```

## Инсталација

### 1. База
Потребен е PostgreSQL со PostGIS (на macOS најлесно со [Postgres.app](https://postgresapp.com/)).

```bash
createdb geocab_app
psql -d geocab_app -f database/geocab_schema.sql
psql -d geocab_app -f database/geocab_lookup_data.sql
```

> Постоечка постара база се надградува со `psql -d geocab_app -f database/geocab_upgrade.sql`
> (може да се изврши повеќе пати).

Во `GEOCAB/settings.py`, во `DATABASES`, сменете го `USER` (и `PASSWORD` ако треба) за вашиот PostgreSQL.

### 2. Python
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate          # само Django табелите (auth, sessions...)
python manage.py seed             # тест податоци: возила, цени, админ, возачи, корисници
python manage.py createsuperuser  # за Django /admin/
python manage.py runserver
```

Апликацијата е на http://127.0.0.1:8000/ .
Тест профилите и нивната лозинка се опишани на врвот на `GEOCAB_APP/management/commands/seed.py`.

> Корисник и возач не можат да бидат најавени во ист прозорец (делат сесија) -
> за тест користете обичен прозорец и Incognito.

## Тестови

```bash
python manage.py test GEOCAB_APP
```

~190 тестови за сите улоги, копчиња и правила. Django креира посебна тест база (`test_geocab_app`),
ја полни од `database/*.sql` и ја брише на крајот - `geocab_app` не се допира.
Тестовите не бараат интернет (OSRM е заменет со фиксно растојание).

### Регистрација со потврда на е-пошта

По регистрацијата се праќа мејл со линк за потврда; профилот се креира дури кога корисникот ќе кликне „Потврди е-пошта“.
Во развој мејлот не се праќа, туку се печати читливо во терминалот каде работи `runserver` - од таму се копира линкот.
За вистински мејл (на пр. Gmail со „App password“) се поставуваат `GEOCAB_SMTP_USER` и `GEOCAB_SMTP_PASSWORD`
во околината (`.env`, не се праќа на GitHub).

### Плаќање со картичка (демо)

Платежната порта е демо (`GEOCAB_APP/card_gateway.py`) - не се наплаќаат вистински пари.
Тест картички: `4242 4242 4242 4242` (одобрено), `4000 0000 0000 0002` (одбиено), кој било иден датум и CVV.
Во базата се чуваат само типот и последните 4 цифри од картичката.

## Тест на телефон (GPS бара HTTPS)

```bash
python manage.py runserver
ssh -R 80:localhost:8000 nokey@localhost.run     # во нов терминал -> https://xxxx.lhr.life
```

Отворете ја `https://...lhr.life` адресата на телефонот и дозволете локација.
Додека тунелот работи, сајтот е јавно достапен - затворете го со Ctrl+C по тестирањето.
На компјутер GPS може да се симулира во Chrome: DevTools → ⋮ → More tools → Sensors → Location.

## Главни правила

| Правило | Каде е |
|---|---|
| Цена = почетна + km × цена по km (по пат), −20% над 10 km | `fn_price_formula`, `fn_estimate_price` |
| Најблизок слободен возач во 10 km, без возачи што одбиле или се блокирани | `fn_find_nearest_driver` |
| Понуда без одговор 5 минути → следен возач | `fn_expire_offers`, `db.OFFER_TIMEOUT_SECONDS` |
| Казна: 0 / 50% / 100% од почетната; no-show 100% | `fn_cancellation_fee` |
| Провизија 20% (се менува во поставки), запишана на секое плаќање | `Platform_settings`, `trg_payment_commission` |
| Провизија за месец М: рок 15-ти во М+1, блокада од 1-ви во М+2 | `fn_driver_debt_status` |
| Дозволени премини на статус на возење | `trg_ride_status_transition` |

## Забелешки
- OSRM и Nominatim се бесплатни јавни сервиси - добри за развој и мал број корисници.
- Ако OSRM не одговори, цената се пресметува по воздушно растојание и апликацијата продолжува да работи.
- Поставките (`DEBUG = True`, клучот во `settings.py`) се за локален развој, не за јавен сервер.
- Контакт податоците (телефон, е-пошта) се во `GEOCAB_CONTACT` во `settings.py`.
